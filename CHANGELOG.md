# Changelog

All notable changes to Safe Update will be documented in this file.

## 1.0-test - 2026-08-12

Initial test release.

### Added

- Modular Safe Update framework
- APT update detection
- Pre-update health checks
- Post-update health checks
- Persistent storage inventory validation
- PostgreSQL backup support
- Filesystem directory backups
- Rootless Podman volume backups
- SHA256 checksum verification
- Archive verification
- PostgreSQL dump verification
- Timeshift system snapshots
- Manual Timeshift rollback
- Backup retention
- Safe Update snapshot retention
- systemd service
- systemd timer
- Portable global configuration
- Modular per-service configuration
- Installation script
- Uninstallation script
- English documentation
- Polish documentation

### Status

This version is experimental and should be tested on each target server before automatic updates are enabled.
